Texto selecionado

Inserir

Para texto existente, clique diretamente sobre a palavra/bloco. O editor permite substituir ou cobrir o conteúdo no PDF exportado.

Como usar

Selecione objetos e arraste. Use Destaque, Retângulo, Linha, Seta ou Desenho para marcações. Imagens e assinaturas podem ser posicionadas e redimensionadas visualmente. Campos são incorporados ao PDF como campos preenchíveis visuais.

✏️ Documento aberto em modo de edição, como no Word. Clique no texto para alterar.
